### 供应链是什么

**供应链**是供应商、工厂、仓库、物流商、销售渠道和客户组成的协作网络。**供应链管理（SCM）**协调需求、采购、生产、库存与交付，在服务水平、成本、资金占用和断供风险之间做权衡。**物流**是其中一环，主要管运输、仓储和退货中的货物流转。[国务院办公厅《关于积极推进供应链创新与应用的指导意见》](https://www.nea.gov.cn/2017-10/13/c_136682814.htm)

### 辽宁东港草莓从田间到餐桌

2025 年 5 月，辽宁丹东东港市圣野浆果专业合作社将一批草莓分拣、装箱、入库预冷。当天下午，1,600 斤草莓装上冷藏车，经深圳口岸运往香港。当地还有电商直销渠道，村级分拣点负责包装，快递企业承接寄递。[辽宁省政府报道](https://www.ln.gov.cn/web/ywdt/zymtkln/2025052609310411642/index.shtml) · [辽宁省农业农村厅产业园案例](https://nync.ln.gov.cn/nync/index/nyyw/zsqsnyxxlb/2023101614171474594/index.shtml)

以合作社向国内商超供货为例，三类流动如下。

- **货物流**。种植户采摘 → 产地分拣、包装和预冷 → 冷藏运输 → 门店冷藏陈列 → 消费者。
- **信息流**。门店把销量和订单传给产地，产地反馈可采量和预计到货时间。收发货时记录批次。
- **资金流**。消费者向门店付款，门店按采购约定与合作社结算，合作社再与种植户结算。

### 上下游各方关心什么

上下游要看站在哪一环。以合作社为例，供果的种植户是上游，向它采购的批发商或商超是下游。换到种植户的视角，种苗、农资供应商又是它的上游。

| 角色 | 要掌握的信息 | 这些信息决定什么 |
| --- | --- | --- |
| 种植户 | 品种、采收期、预计产量、买方要求的果径和成熟度 | 种多少、何时采、能承诺多少合格果 |
| 合作社或产地采购商 | 各农户可交量、各等级果的占比、包装和预冷能力 | 能接多少订单、如何把分散的货凑成一车 |
| 仓配与承运方 | 提货时间、车厢温度要求、门店收货时段 | 何时装车、怎样排路线、延误时通知谁 |
| 批发商、门店或加工厂 | 批发商看行情和周转，门店看销量和剩余可售期，加工厂看原料规格和排产 | 不同等级的果发往哪里、何时补货或调整售价 |

### 从采购到结算

- **采购与报价**。订单农业会提前约定品种、数量、质量、价格或定价方式、交货时间和付款条件。比较两笔草莓报价时，要统一等级和净重，并确认包装、运费由谁承担。[农业农村部《订单农业合同规范指引》](https://fgs.moa.gov.cn/zfjd/202601/t20260120_6480835.htm)
- **交货与验收**。收货方按订单核对批次、净重、果况和到货时间。若有压伤或短重，记录受影响数量，由双方按约定确认接收、退货或折价，再据此对账。[市场监管总局《农副产品买卖合同》示范文本](https://htsfwb.samr.gov.cn/View?id=8ed1cb2d-568e-41da-b4f3-4b1671c51af4)
- **每公斤可售成本**。以下为算例。假设采购 100 公斤草莓花 1,000 元，包装和冷运共 200 元，损耗后有 90 公斤可售，则每公斤可售果分摊成本约为（1,000 + 200）÷ 90 = **13.33 元**。这比只看采购单价更能反映损耗的影响。
- **账期与垫资**。如果合作社收果当天付给农户，商超验收后 30 天才付款，合作社就要先垫付收购款。估算资金需求时，要看这段时间内有几批货同时等着回款。

### 业务单据与对账

以商超向合作社采购一批草莓为例。双方可以用订单号关联单据，再按商品、批次和计量单位核对明细。

| 环节 | 看哪张单 | 核对什么 |
| --- | --- | --- |
| 订货 | 采购订单 | 订了哪个规格、多少盒、每盒多少钱、何时到货 |
| 交接 | 送货单、验收记录 | 送到多少、实收多少、拒收多少，差异由双方确认 |
| 入库与退货 | 入库单、退货单 | 合格品按批次入库。已入库后又退回的，关联原单扣减库存 |
| 对账与付款 | 对账单、发票、付款回单 | 按约定核对结算数量和单价，付款后将回单与对应应付款匹配 |

**对账算例**。假设订货 100 盒，每盒 12 元，送达 100 盒，其中 4 盒压伤，当场拒收。若约定按验收合格数结算，本批入库 96 盒，应付 **1,152 元**。这 4 盒记录在验收差异中，后续盘点时无需再扣一次。[财政部采购业务解读](https://kjs.mof.gov.cn/zhengcejiedu/201006/t20100611_322435.htm) · [财务笔记中的付款与核销](../财务/README.md#付款单与核销)

### 生鲜供应链的关键点

- **分级与损耗**。按大小、成熟度和外观分级，同批草莓可按规格卖给不同渠道。规格不符的果实若仍符合加工要求，可转去加工。霉变报废单独记录，便于定位采摘、运输或门店环节的损耗。
- **预冷与冷链**。采后尽快预冷，去除田间热。冷藏运输、仓储和陈列继续控温，交接时检查温度和果况。[辽宁省政府报道的东港预冷与运输实例](https://www.ln.gov.cn/web/ywdt/zymtkln/2025052609310411642/index.shtml)
- **批次追溯**。把产地、采摘日期、包装批次和发货去向关联起来。有问题时，可以查到这批来自哪里、发到了哪些门店。[辽宁省农业农村厅东港草莓追溯调研](https://nync.ln.gov.cn/nync/index/nyyw/nyxw/gzdt/2026012209565195456/index.shtml)

### 计划、库存与风险

- **供需计划**。门店结合销量、周末和促销估计需求，产地根据天气、成熟度和可采量滚动调整供货计划。
- **提前期与补货**。从下单到验收可售的时间就是补货提前期。假设门店每天卖 20 盒、次日到货、留 5 盒安全库存，库存位置（可售现货 + 在途订单 − 欠交量）降到 25 盒（20 × 1 + 5）时就补货。实际补货时，还要看批次的剩余可售期，优先销售快到期的批次。
- **牛鞭效应**。促销期间门店集中加单，合作社把临时需求当成长期增长再加量备货，可能让上游波动放大。共享实际销量和促销计划可以减少误判。[清华大学出版社《供应链概述》](https://www.tup.tsinghua.edu.cn/upload/books/yz/096994-02.pdf)
- **供应链韧性**。单个产地因天气减产时，可从已验收合格的备选产地调货。鲜果可售期短，备选货源和小批补货能减少对大量备货的依赖。

### 常用指标

| 指标 | 回答的问题 |
| --- | --- |
| 准时足量交付率（OTIF） | 有多少订单同时满足约定交期和数量？ |
| 订单履约周期 | 从收到订单到交付用了多久？ |
| 库存可用天数 | 按当前消耗速度，现有库存还能用几天？ |
| 门店报废率 | 同一批次因霉变、破损等报废的重量占该批次入库重量多少？ |

### 供应链关键字速查

| 关键字 | 英文或简称 | 在草莓业务中怎么用 |
| --- | --- | --- |
| 库存单位 | SKU | 同品种的 250 克装和 500 克装分别计库存、定价和补货 |
| 批次 | Lot / Batch | 同一规格今天到的货分属两个采摘批次，可分别追溯去向 |
| 计量单位 | UOM | 采购按箱、销售按盒。若该规格每箱 12 盒，验收入库 8 箱即 96 盒 |
| 先到期先出 | FEFO | 同规格多批货在库时，优先发剩余可售期短且能满足客户收货要求的一批 |
| 订单管理系统 | OMS | 接收商超或电商订单，跟踪已订、已发和已取消的数量 |
| 仓储管理系统 | WMS | 记录哪批草莓在哪个库位，指导收货、拣货和盘点 |
| 运输管理系统 | TMS | 合并配送任务、安排冷藏车辆，记录到店时间和签收结果 |
