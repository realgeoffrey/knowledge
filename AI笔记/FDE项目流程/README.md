## 启用与迁移

保留 `ai/`、`sources/`、`spec/`、`prototypes/` 四个文档目录；实际工程按既有结构保留。根 README 只简记当前阶段、实际阻塞与下一步，不再单建项目状态页。

`spec/` 可由 AI 起草和更新，人评审业务决定。新增资料由人存入 `sources/` 并明确要求 AI 导入；日常从现行规格工作，不自动重读全部原件。

已有项目先把当前有效规则、关键异常和验收预期归入唯一所属章节，再移除重复正文；确认原型、链接和检查可用后删除旧过程文档。原始资料、真实业务行为和已有工程不因换模板而改变。

只维护当前规格与必要补充，不新增阶段门禁、会议副本、迭代台账或归档副本。改变已确认业务仍需人的明确决定，详细技术选择由 AI 在业务约束内完成。实际命令见 [AI 说明](ai/README.md#检查命令)。
