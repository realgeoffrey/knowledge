# 客户原始需求与访谈资料

> **AI维护｜人无需日常阅读。**

本目录存放客户提供的原始需求文档、访谈记录、录音或转写、业务表格、图片等。

保留原件，将提炼后的业务规则与验收条件写入 [需求文档](../specs/requirements.md)。在需求来源或对应任务中注明原件路径、日期或版本、提炼去向与未处理部分。

针对某份资料的疑问统一写入 [问题与澄清记录](../records/clarifications.md)，注明原件路径、形成日期或数据期间、收到日期、版本及页/段/时间点，关联受影响需求；不在原件中覆盖问题答复。

原件保留原名和内容；需要按日期辨认时按 [命名规则](../handbook/maintenance.md#日期与迭代顺序) 处理。仅转写或转换的资料沿用来源分类。
