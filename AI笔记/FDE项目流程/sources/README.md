# 项目原始资料

本目录由人维护，保留原件的名称、正文、来源及时间关系。原始需求放 `客户原始需求/`；会议记录按实际日期建目录，例如 `会议记录/YYYY.MM.DD/`，同日多场可附主题。

现行业务规格统一在 [spec](../spec/README.md) 维护。本目录只保存原始需求、会议记录、附件和样本，不另存需求规格副本。

AI 日常从现行规格工作，不自动读取新增原件。用户要求导入资料或核对指定内容时，再读取相关原件，将已确认结论更新到对应规格及实现。与现行规格冲突的提议，先说明差异并请用户确认。必要出处可简记资料名、日期及页码或条目，不复制会议正文或另建 AI 纪要、版本台账。
