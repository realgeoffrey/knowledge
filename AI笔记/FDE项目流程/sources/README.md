# 项目来源资料

> **人维护，AI 只读。** 本目录是项目原始资料的固定存放位置。

## 资料放置与命名

| 模板位置 | 放什么、怎么命名 |
| --- | --- |
| [客户原始需求/](客户原始需求/) | 放客户提供的初始需求、附件和样本。原件保留原名、内容及来源。 |
| [会议记录/](会议记录/) | 按实际会议日期新建 `YYYY.MM.DD/`，如 `2026.11.17/`。同日有多场时可加主题，如 `2026.11.17-需求评审/`。新写的纪要可用 `README.md`，已有纪要、录音和截图沿用原名。 |
| [软件需求规格说明.md](软件需求规格说明.md) | 放在人维护的 `sources/` 根目录，固定用 `软件需求规格说明.md` 作为现行规格入口。 |

已有项目可沿用实际路径，在根 README 和[项目概况](../ai/specs/project.md#原始资料位置)更新链接。人工更正由人在此维护，也可在对话中指出要改的行为。

只供 AI 作背景的资料可在本页注明 `仅供 AI 阅读`，仍存放在 `sources/`。

AI 转写、OCR、补充纪要写入 [ai/meetings/](../ai/meetings/)，提炼后的规则和验收条件写入 [需求文档](../ai/specs/requirements.md)。引用原件路径、适用版本及对应段落或媒体时间点，便于核实与重新整理。
