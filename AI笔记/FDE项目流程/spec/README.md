同一规则只定义一次，其他章节用相对链接和固定锚点引用。已有需求保留稳定 REQ/AC 编号；模板中的占位编号和示意图不算真实条目。不要每期复制整套文档；仅实际需要时按模块或场景拆成命名明确的 Markdown。

人必须关注范围、权限、审批、金额、实物/库存、质量、履约及责任，即使它们是异常分支。内部命名、页面排序、事务实现与索引等细节由 AI 在这些约束内决定，必要技术补充放 [ai/](../ai/README.md)。

原始资料在 [sources](../sources/README.md)，用户要求导入或核对指定内容时才读取。明确结论更新到唯一所属章节，不复制会议正文或维护迭代台账。原型不能反过来缩减业务范围或把演示选择变成业务决定。
