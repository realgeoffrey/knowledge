# 共享业务规则

这里只定义跨模块约束。模块专属规则留在模块；重复使用时引用，而不是复制一遍。

| 主题 | 需要明确的业务约束 |
| --- | --- |
| 角色与数据范围 | 谁可操作、可访问哪些记录和字段；附件、导出与直达详情同样受控；适用的异人授权 |
| 数量与金额 | 单位与换算、精度和舍入、计价来源、累计/剩余口径、重复或并发后的合法结果 |
| 时间与快照 | 时区、边界时刻、有效期、历史数据和已生效单据采用哪个口径 |
| 状态与纠正 | 何时允许修改、取消、部分执行或作废；已发生事实怎样更正 |
| 外部协作 | 双方职责、重复与乱序、部分失败、结果不明的核实与恢复 |

复杂条件使用决策表，明确每行条件、允许动作、结果及禁止情况。没有依据的关键政策应明确列出待决定事项、建议选项及影响，由业务负责人决定后再写入规格；普通可逆技术选择留给实现。

具体规则在此按主题展开并设置稳定锚点，模块、状态和验收引用这些锚点。不要预设某个客户的金额、库存、审批或监管阈值。
